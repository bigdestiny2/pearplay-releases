# PearPlay desktop previews

Your games. Your peers.

[Meet PearPlay](https://pearplay.bigdestiny-bd.chatgpt.site/) · [Desktop downloads and release notes](https://github.com/bigdestiny2/pearplay-releases/releases)

This is the public distribution repository for PearPlay. It contains release notes and packaged desktop previews. The main development repository is private.

## Platforms

- **macOS, Apple silicon (arm64):** a native desktop application with its runtime included.
- **Windows, 64-bit (x64):** a portable desktop application with its runtime included. Extract the entire ZIP before opening PearPlay.exe.

No separate Node installation or browser is required. Downloads are development previews, not a stable production release. Read the release-specific test and signing status before downloading. The current previews are unsigned by a trusted publisher; macOS builds are not notarized. Your operating system may block them. No security-bypass instructions are provided.

## Verification

Each preview includes SHA-256 checksums and a provenance record. macOS and Windows have separate test status. Current packages are built from a recorded worktree snapshot; the release tag in this distribution repository is not the application source revision. Required runtime code and applicable third-party license notices are included in each application. The broader source snapshot stays private.

PearPlay is being built toward a peer-to-peer gaming platform. Large-scale multiplayer, production commerce and AAA distribution remain roadmap work.
